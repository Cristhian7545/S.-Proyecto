# S. Proyecto

Sorpresa interactiva

Abre [index.html](index.html) en el navegador. Desde la pradera, pulsa **¿Empezamos?** para elegir un vinilo. Si el navegador bloquea el inicio automático, pulsa **Activar música**.

- [escenas](escenas) contiene Carta, Luces, Flores, Luz y el cuento musical de Baile.
- [css](css) y [js](js) contienen los estilos y las animaciones.
- [assets](assets) contiene las imágenes y la música.
- [pruebas](pruebas) reúne las versiones experimentales. El ensayo de baile 3D carga Three.js desde un CDN.
